# bKash Clone App 💳

A modern and responsive **bKash Clone Flutter App** built using **Flutter** and **Provider State Management**.  
This project recreates the core UI design of the bKash mobile application including the **Splash Screen**, **Home Screen**, **Menu Drawer**, and **Profile Screen** using dummy data.
